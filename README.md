Daily Task Manager
Project Overview

Daily Task Manager is a Python-based console application that helps users manage their daily tasks. Users can add tasks, view tasks by priority, check pending tasks, and mark tasks as completed.

Objectives
To manage daily tasks easily.
To organize tasks according to priority.
To track pending and completed tasks.
To understand Python programming concepts.
Features
Add new tasks with a title, priority, and due date.
Generate a unique Task ID automatically.
View tasks according to priority (High, Medium, Low).
Display all pending tasks.
Mark tasks as completed.
Validate priority and date format.
Save tasks automatically in a text file.
Technologies Used
Language: Python 3
Concepts: Lists, Dictionaries, Functions, Loops, Conditional Statements, File Handling
Storage: tasks.txt
Requirements
Python 3 installed on your computer.
VS Code or any Python-supported editor.
How to Run
Download or clone the project.
Open the project folder in VS Code.
Open the terminal.
Run the following command:
bash
python one.py

Select an option from the menu and manage your tasks.
Menu Options
Add Task
View by Priority
Show Pending
Complete Task
Exit

Note: The tasks.txt file is created automatically when the first task is added.

Test Cases
Test Case 1: Add a task with valid details.
Test Case 2: Display a message when no pending tasks exist.
Test Case 3: Handle invalid priority, date, and Task ID.
Test Case 4: View tasks by priority and mark a task as completed.
Conclusion

This project provides a simple way to manage daily tasks using Python. It demonstrates basic programming concepts and file handling while helping users organize their work efficiently.
